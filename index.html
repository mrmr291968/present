Como funciona

Um resumo para você saber onde ficam suas coisas.

Suas fotos e vídeos

  • Use Guardar foto ou vídeo para adicionar uma mídia. Ela fica guardada neste navegador e aparelho.
  • Favoritos, recadinhos, playlists e ideias próprias também ficam salvos neste aparelho.
  • O site não envia suas mídias para a internet nem sincroniza automaticamente com outros aparelhos.

Backup

  • Toque em Backup para baixar um arquivo .perehub com suas mídias e organização.
  • Guarde esse arquivo em um lugar seguro. Para recuperar, abra o PereHUB e use Restaurar.
  • Restaurar adiciona os itens do backup à biblioteca que já existe.

Ideias de vídeo

  • Toque em Minha ideia para escrever e salvar uma sugestão sua.
  • Use o coração para guardar ideias favoritas. Elas entram no backup junto com as suas ideias próprias.
  • O botão Me surpreende escolhe uma sugestão aleatória.
Privacidade: os arquivos ficam neste navegador e aparelho. Use Backup para guardar uma cópia; o site não envia as mídias para a internet.
